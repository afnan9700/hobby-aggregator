# AGENTS.md

This module is the Spring Boot backend for the hobby aggregator.

Primary stack:

* Spring Boot
* Spring Security
* Keycloak
* JPA
* Maven
* SLF4J
* Docker

Responsibilities:

* API endpoints
* Authentication and authorization
* Persistence and domain logic
* Integration with Keycloak
* Database access through JPA

Rules:

* Follow `docs/conventions/spring-boot.md`.
