# AGENTS.md

This repository contains a hobby aggregator application.

Goals:

* Keep the codebase readable and maintainable.
* Treat authentication and authorization as first-class concerns.
* Keep project structure consistent across modules.

Workflow:

* One a high level: spec -> plan → implement → test → review → update docs.
* For smaller changes, additions, or fixes, a simpler flow is followed.
* `app-state` tell about the current state of the application.
